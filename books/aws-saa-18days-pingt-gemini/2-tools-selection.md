第1章では、教科書・Ping-t・AWS Skill Builder・Google Gemini の4つを「役割がかぶらないように振り分けた」とだけ書きました。この章では、その振り分けをもう一段具体にします。どの道具に何を任せるか、どこからお金がかかるか、18日の中でどの道具にどれくらい時間を割いたか、そして情報が食い違ったときにどれを優先するか、です。

最初にお断りしておくと、ここに書く配分は**筆者個人の体験**です。前職で AWS を触っていた前提があってこその配分なので、経験量や使える時間が違えば、比率は変えて構いません。むしろ変えるべきだと思います。

---

## この章で決めること

この章を読み終えたときに、次の4つが手元で決まっている状態を目指します。

1. 4つの道具それぞれに「何を任せ、何を任せないか」
2. どこまで無料で進め、どこからお金を払うか
3. 18日の中で、どの時期にどの道具を主役にするか
4. 道具どうしで説明が食い違ったときの優先順位

周回の具体的な手順は第3章・第4章、Gemini への聞き方は第5章、試験当日の戦い方は第6章で扱います。この章はあくまで「道具の棚割り」です。

## 4ツールの役割分担（かぶらせない）

短期決戦で一番もったいないのは、同じことを複数の道具で二重にやることです。たとえば教科書で読んだ内容を Gemini にもう一度要約させたり、Ping-t の解説で足りているのに公式ドキュメントを最初から読み込んだりすると、時間がいくらあっても足りません。筆者は次のように割り切りました。

| 道具 | 任せること | 任せないこと |
|---|---|---|
| 教科書 | 知識の棚卸し、弱い領域の穴埋め（辞書的に引く） | 通読、試験の問い方への慣れ |
| Ping-t | 演習・模擬で「試験の型」に慣れる（本書の主役） | 体系的なインプットの代わり |
| AWS Skill Builder | 公式の言い回し・範囲感の確認、受験予約への導線 | 大量演習 |
| Google Gemini | 間違えた箇所の「なぜ」を深掘りする補助 | 正解の判定、丸暗記の素材づくり |

**教科書**は、第1章と同じく『AWS認定資格試験テキスト AWS認定 ソリューションアーキテクト − アソシエイト教科書 第3版［SAA-C03］対応』を使いました。最初から最後まで読むのではなく、Ping-t で間違えた領域や、実務で触れていなかったサービスの章を開く使い方です。地図として手元にあると、演習で迷子になりにくくなります。

**Ping-t** は、本書の中心です。問題を解き、解説を読み、間違えたところを潰す、という流れの大半はここで回しました。試験レベルの模擬で手応えが出るかどうかを、受験判断の目安にしています。

https://ping-t.com/
https://mondai.ping-t.com/

**AWS Skill Builder** は公式の学習サイトです。筆者は大量演習の場ではなく、「公式はこの範囲・この言い方で出してくる」という感覚を確かめる場所として使いました。受験予約（Pearson VUE）への導線としても便利でした。

https://skillbuilder.aws/

**Google Gemini** は、あくまで補完です。間違えた問題について「なぜその選択肢が誤りなのか」「実務ではどう使うのか」を聞き、自分の言葉で説明できるまで掘り下げる用途に限定しました。AI の回答を正解として扱わない、というのが大前提です。

https://gemini.google.com/

## 課金／無料の境界

費用面での基本方針は「お金を払うのは Ping-t のプレミアムと教科書だけ。公式と AI は無料で使える範囲で進める」でした。

| 道具 | 筆者の使い方 | 費用 |
|---|---|---|
| 教科書 | 購入して手元に置く | 購入が必要（価格は書店・EC でご確認ください） |
| Ping-t（SAA-C03） | 「SAA-C03 最強WEB問題集」をプレミアムで利用 | 一部は無料、フルに使うにはプレミアムが必要 |
| AWS Skill Builder | 無料で使える範囲 | 筆者は無料の範囲で足りました |
| Google Gemini | 無料で使える範囲 | 筆者は無料の範囲で足りました |

Ping-t プレミアムの料金は、公式ページ（https://mondai.ping-t.com/g/premium_plans ）で次のように案内されています。

| 期間 | 料金 |
|---|---|
| 1ヶ月 | 2,640円 |
| 2ヶ月 | 3,300円 |
| 3ヶ月 | 3,960円 |
| 6ヶ月 | 4,950円 |
| 1年 | 6,930円 |

いずれも一括払いで、自動更新はない形式と案内されています。18日で終える計画なら、筆者のように短い期間のプランでも足ります。ただし、予定どおりに進まなかったときの延長も考えて、少し長めのプランを選ぶのも一つの考え方です。

:::message
上記の料金・プラン内容は**執筆時点**で公式ページを確認したものです。料金や提供内容は変更される可能性があります。**申し込み前に必ず公式ページで最新の情報を確認してください。**
:::

混同しやすい点を一つ補足します。Ping-t には AWS の別資格（クラウドプラクティショナー、CLF）向けに無料で使えるコンテンツもありますが、本書が対象にしているのは SAA-C03 です。「Ping-t は無料で AWS の問題が解ける」と聞いて始めると、SAA の問題集の全体は無料では使えない、という点で戸惑うかもしれません。

Skill Builder と Gemini には有料のプランやオプションもありますが、筆者は使っていないため、その中身や効果についてはここでは書きません。筆者の場合は「無料で使える範囲で足りた」という体験ベースの話として受け取ってください。

もう一つ、第1章で触れた**勤務先の研修枠**も費用の境界に関わります。教材費や受験料の補助がある会社なら、自腹の範囲はさらに小さくなります。申し込む前に、自分の会社の制度を確認しておくことをおすすめします。

## 何をどれだけ回すか（時間配分の目安）

18日をざっくり前後半に分けると、主役の道具が入れ替わります。以下は筆者の体験から見た「重心」の目安で、時間を厳密に計った記録ではありません。

| 時期 | 主役 | 脇役 | 重心のイメージ |
|---|---|---|---|
| 1〜14日（基礎固め） | 教科書＋Ping-t の演習 | Skill Builder | インプットと演習を並走。穴がある領域は教科書へ戻る |
| 15〜18日（模擬の猛特訓） | Ping-t の試験レベル模擬 | 教科書（引くだけ） | 試験の型に慣れることに集中 |
| 最終仕上げ | Gemini＋Ping-t の解説 | 公式ドキュメント | 間違えた問題だけを深掘りして潰す |

ポイントは三つです。

- **Ping-t は最初から最後まで触る**。前半は演習、後半は模擬と、使い方は変わっても手を止めません。
- **教科書は「読む」から「引く」へ移す**。前半は穴埋めのために開きますが、後半は模擬で迷ったときに該当箇所を引く辞書になります。
- **Gemini は後半に寄せる**。間違えた問題が溜まってから使う方が、聞くべきことがはっきりして効率がよかったです。

一日の中での配分も、同じ考え方です。「新しく覚える時間」と「解いて間違える時間」と「間違いを潰す時間」を分けて、どれか一つに偏らないようにしました。実務経験が少ない方は、前半の教科書の比重を上げ、期間そのものを延ばす前提で調整してください。

具体的に何問を何周するか、日ごとに何をやるかは、第3章（1〜14日）と第4章（15〜18日）で書きます。

## 公式（Skill Builder／ドキュメント）との優先順位

道具を4つ使うと、説明が微妙に食い違う場面が出てきます。筆者は次の順番で判断しました。

| 優先度 | 情報源 | 扱い |
|---|---|---|
| 1 | AWS 公式（ドキュメント、Skill Builder、Well-Architected の考え方） | 判断の基準。食い違ったらこちらを採る |
| 2 | 教科書 | 体系的な整理として信頼するが、出版後の仕様変更はあり得る |
| 3 | Ping-t の解説 | 試験の問い方に即した説明として重視。疑問が残れば公式で確認 |
| 4 | Gemini の回答 | 理解の補助。単独では根拠にしない |

AWS のサービスは更新が速いので、教科書や問題集の記述が最新の仕様とずれていることもあり得ます。また、Gemini はもっともらしい誤りを返すことがあります。「AI がこう言っていたから」で覚えるのではなく、気になったら公式で裏を取る、という一手間を習慣にしておくと安全です。

一方で、公式ドキュメントを最初から網羅しようとすると、短期決戦では時間が足りません。公式は「確認のために引く場所」、演習は Ping-t、と役割を分けておくのが筆者のやり方でした。

## 研修枠がある場合の組み込み方

第1章で書いたとおり、18日に圧縮できたのは当時の勤務先の研修枠に支えられた部分が大きいです。制度は会社ごとに違うので、ここでは考え方だけを置きます。

- **時間の枠がある場合**：業務時間内に学習できるなら、集中力が必要な模擬（後半の Ping-t）をそこに当てると効果を感じやすいです。
- **教材費の補助がある場合**：教科書や Ping-t プレミアムが対象になるかを先に確認します。対象なら、プラン選びで迷う理由が一つ減ります。
- **受験料の補助がある場合**：受験日を先に決めやすくなります。期限があると、18日という短い計画も立てやすくなります。

申請に時間がかかる会社もあるので、学習を始める前に制度を確認しておくのがおすすめです。使えるものがあるなら、個人で全部を抱え込まない方が続きやすいと思います。

## 次章予告

道具の棚割りが決まったら、いよいよ1〜14日の基礎固めです。第3章では、教科書と Ping-t の演習をどう並走させたか、実務で触れていたサービスの「再確認」と未経験サービスの拾い方、そして日々の最低ラインをどこに置いたかを書きます。

繰り返しになりますが、これは一人のインフラ実務者の体験であり、合格を保証するものではありません。自分の経験量や使える時間に合わせて、道具の比重や日数を組み替えながら読み進めてください。
